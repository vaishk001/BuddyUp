# BuddyUp
=======
# Chat Application (React + Firebase + Cloudinary + Framer Motion)

This is a starter scaffold for a real-time chat web application using React, Framer Motion, Firebase, and Cloudinary.

What is included:

- Project scaffold (Vite + React)
- Tailwind CSS config stubs
- Basic React entry (`src/index.jsx`, `src/App.jsx`)
- Placeholder Firebase config (`src/firebase.js`)
- Cloudinary helper stub (`src/utils/cloudinary.js`)
- Basic components scaffolding under `src/components`

Next steps:

1. Run `npm install` to install dependencies.
2. Add your Firebase config to `src/firebase.js`.
3. Configure Cloudinary credentials in environment variables and update `src/utils/cloudinary.js`.
4. Start dev server with `npm run start`.

Notes:

- This is a scaffold only; authentication flows, Firestore rules, and full features still need implementation.
